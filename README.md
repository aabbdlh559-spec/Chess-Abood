# Chess Abood v2.0 • العدسة الذكية ومساعد الشطرنج العائم (Android 16)

## التحسينات الذكية في الإصدار 2.0
1. **الاكتشاف التلقائي للرقعة (`autoDetectBoardRect`):** يحدد مكان رقعة الشطرنج (8×8) على الشاشة تلقائياً بدقة البكسل دون الحاجة لضبط يدوي معقد، مع إطار شبكة ذهبي خفيف لتأكيد القفل البصري.
2. **مقاومة ألوان التظليل (Last-Move Highlights):** يحسب خلفية كل مربع من حوافه المحلية الأربعة، مما يمنع اعتبار المربعات الصفراء/الخضراء الفارغة قطعاً وهمية، ويستخدمها لتحديد صاحب الدور بدقة.
3. **متتبع النقلات القانونية ومنع تشويش الحركة (`Legal Move Game-State Tracker`):**
   - ينتظر ثبات الإطارين المتتاليين لتجنب قراءة القطع أثناء انزلاقها على الشاشة.
   - يطابق التغيرات على الرقعة مع النقلات القانونية من الوضع السابق، فلا تتحول قطعة إلى أخرى ولا يضيع حق التبييت أو صاحب الدور.
   - يفحص صحة وضع FEN (وجود ملك واحد لكل لون وعدم وجود بيادق في الصف الأول/الأخير) قبل إرساله للمحرك.
4. **كتاب افتتاحيات الأساتذة (Opening Book) + محرك بحث تكتيكي أعمق:** ردود فورية في الافتتاحيات وتحليل أعمق في وسط ونهاية الدور، مع التنبيه الواضح عندما يكون الدور للخصم.
